# Gerador de Panfletos de Gôndola - WellFarma

Aplicativo web desenvolvido em **HTML, CSS e JavaScript** para geração de cartazes e panfletos de gôndola de farmácia com a tipografia oficial **Amsi Pro Ultra** e preservação de **100% das cores originais** do arquivo.

---

## 🚀 Como Iniciar

1. **Clique Duplo:** Dê um clique duplo no arquivo [`iniciar_programa.bat`](file:///d:/GRUPO%20WELL/LINK%20G%C3%94NDOLAS%20WF/iniciar_programa.bat)
2. **Ou abra diretamente:** Abra o arquivo [`index.html`](file:///d:/GRUPO%20WELL/LINK%20G%C3%94NDOLAS%20WF/index.html) em qualquer navegador moderno (Edge, Chrome, Opera, Firefox).

> O programa funciona **100% offline**, sem necessidade de internet, Node.js ou instalação de pacotes.

---

## ✨ Atualizações Recentes

1. **Fonte Amsi Pro Ultra Integrada:**
   - A fonte oficial **Amsi Pro Ultra** (arquivo TTF baixado e incorporado) agora é aplicada diretamente tanto no **Nome do Produto** quanto no **Valor / Preço**, garantindo 100% de fidelidade visual com a arte original.
2. **Cores Originais Preservadas (Sem Conversão):**
   - O arquivo PDF e as imagens são gerados diretamente com as cores originais da arte (RGB / sRGB), sem conversões que causem perda de saturação ou desvio de tonalidade.

---

## 📄 Opções de Download em PDF

- **4 Panfletos por Folha A4 (Grade 2x2):** Monta 4 panfletos na mesma folha A4 com guias pontilhadas para corte com guilhotina ou tesoura.
- **A4 (Folha Inteira - 1x):** 1 panfleto grande ocupando a página A4 inteira.
- **2 Panfletos por Folha A4 (A5):** 2 panfletos por folha em orientação paisagem.
- **Salvar PNG HD:** Imagem em alta resolução (1448 x 2048 px).
- **Imprimir Direto:** Atalho de impressão com layout otimizado.
